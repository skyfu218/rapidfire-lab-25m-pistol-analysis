# RapidFire Lab｜25 公尺快射影像分析

瀏覽器端單鏡頭教練輔助工具，結合 MediaPipe Pose、射手 ROI 與槍枝 ROI，分析肩臂投影角、肘角、軀幹側傾、槍枝位移與疑似擊發峰值。

## 功能

- 匯入本機影片、相機與示範模式
- 框選射手 ROI，降低相鄰選手或裁判干擾
- 點選槍枝 ROI，追蹤上下與水平位移
- 肩臂投影角、肘角、軀幹側傾時間序列
- 分析區間選擇、疑似擊發峰值、CSV 與 PNG 報告
- 影片只在使用者瀏覽器本機處理，不上傳伺服器

## 本機預覽

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。首次載入姿態模型需要網路。

## 量測邊界

本工具為單鏡頭影像估算，不是真實 3D 動作捕捉或校準瞄準軌跡儀。角度及穩定度受視角、像素、遮擋、壓縮、相機防震與模型信心影響，不應用於醫療、槍枝安全或正式成績判定。
