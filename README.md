# RapidFire Lab｜25 公尺快射影像分析

瀏覽器端單鏡頭教練輔助工具，結合 MediaPipe Pose、射手 ROI、槍枝 ROI 與選用的綠燈 ROI，聚焦單次射擊的反應、舉槍、穩定、疑似擊發與回復節奏。

## 功能

- 匯入本機影片、相機與示範模式
- 框選射手 ROI，降低相鄰選手或裁判干擾
- 自適應骨架穩定化：以 ROI 身分黏著、低信心短暫保持、速度離群抑制與 One Euro Filter 降低關節跳點，亦可切回原始骨架檢查
- 點選槍枝 ROI，追蹤上下與水平位移
- 影片載入後可用 ROI 定位時間軸、播放／暫停與逐格按鈕，先找到舉槍畫面再設定槍枝 ROI
- 肩抬舉角（垂下 0°、水平 90°、頭上 180°）、肘屈曲角（伸直 0°）與軀幹側傾時間序列
- 分析區間選擇、疑似擊發峰值、CSV 與 PNG 報告
- 單次射擊事件時間軸：綠燈、動作啟動、舉槍完成、穩定建立與疑似擊發
- 依序分析兩部影片，並以舉槍點或擊發點同步播放、拖曳與即時比較
- 只分析試次 A 時即可完整顯示影片、時間軸、即時判讀與全部 A 欄數據；試次 B 為選用
- 角度與穩定度時間軸以實線顯示 A，加入 B 後以虛線疊圖比較
- 試次 A／B 可各自播放、暫停、拖曳及 0.25×～1× 慢速播放；也可在任意定格位置以鎖頭建立人工同步基準，再改用單一共同時間軸
- 「這一發的動作旅程」並列呈現試次 A、B 的反應、舉槍、穩定與擊發時間
- 舉槍完成相對高度一致性、擊發後最大跳動與回復時間
- 時間序列曲線可個別勾選，Y 軸標示角度與相對位移單位
- ISSF 資格賽 8／6／4 秒系列節奏尺（平均秒數僅作換算參考，不是單發規則上限）
- 影片只在使用者瀏覽器本機處理，不上傳伺服器

## 本機預覽

```bash
python3 -m http.server 8080
```

開啟 `http://localhost:8080`。首次載入姿態模型需要網路。

## 量測邊界

本工具為單鏡頭影像估算，不是真實 3D 動作捕捉或校準瞄準軌跡儀。穩定化可減少視覺抖動與人物切換，但不等於提高真實 3D 量測準確度；角度及穩定度仍受視角、像素、遮擋、壓縮、相機防震與模型信心影響，不應用於醫療、槍枝安全或正式成績判定。
